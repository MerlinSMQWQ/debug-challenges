# 初始事故记录

这些文件来自出题准备阶段的一次真实日结批次运行，保留运行结果，不包含诊断结论。目录重构后的记录于 2026-10-10 在本题实测环境重新生成。

| 文件 | 含义 |
| --- | --- |
| `job.log` | 调度程序记录的启动事件与转换进程 PID |
| `launcher.log` | 程序启动输出及未处理异常；没有内容时为空 |
| `observation.json` | 运行保护结束任务时记录的状态、退出码与耗时 |

PID 和耗时属于当次记录，不是可重复使用的进程编号。请用运行脚本建立自己的现场；任务已结束，不能再向这些历史 PID 发送信号。
